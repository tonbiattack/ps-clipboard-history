# PowerShell製クリップボード履歴ツール 仕様書

## 1. 目的

Windows標準のクリップボード履歴を補助するため、PowerShellのみで動作する簡易クリップボード履歴ツールを作成する。

会社PCでの利用を想定し、以下を重視する。

- exe不要
- Go / Node.js / Python不要
- 管理者権限不要
- 外部通信なし
- インストール不要
- Windows標準のPowerShellのみで動作
- `.ps1` を毎回手動実行しなくても利用できること

## 2. 対象環境

- Windows 10 / 11
- Windows PowerShell 5.1以上
- PowerShell 7でも可能な範囲で互換性を持たせる

## 3. 構成

以下のスクリプトを基本構成とする。

```text
ps-clipboard-history/
├─ clipboard-watch.ps1
├─ clipboard-watch.vbs
├─ clipboard-select.ps1
├─ install-shortcut.ps1
└─ history.json
```

### clipboard-watch.ps1

クリップボードを監視し、変更されたテキストを履歴に保存する。

### clipboard-select.ps1

保存済み履歴を一覧表示し、選択した内容を再度クリップボードへ設定する。

### install-shortcut.ps1

`clipboard-select.ps1` を簡単に起動するデスクトップショートカットと、ログイン時に監視を開始するスタートアップショートカットを作成する。スタートメニューには項目を作成しない。

### setup.ps1

デスクトップショートカット作成、ログイン時の自動起動設定、常駐アプリ起動を一度に行う利用者向けの入口。

### clipboard-watch.vbs

`clipboard-watch.ps1` をコンソールウィンドウなしで常駐起動するランチャー。

常駐中は通知領域にアイコンを表示し、右クリックメニューから履歴表示と終了を操作できる。

管理者権限を要求せず、現在ユーザーのみを対象とする。

## 4. 履歴保存仕様

履歴はJSON形式でローカル保存する。

保存先の初期値は以下とする。

```text
%LOCALAPPDATA%\clipboard-history\history.json
```

1件の履歴は以下の情報を持つ。

```json
{
  "content": "git status",
  "createdAt": "2026-09-11T00:00:00",
  "lastUsedAt": "2026-09-11T00:00:00",
  "useCount": 1
}
```

## 5. 保存件数

初期値は直近50件とする。

最大件数を超えた場合は、最も古く使用された履歴から削除する。

```text
MAX_HISTORY = 50
```

将来的に設定ファイルで変更可能としてもよい。

## 6. 監視仕様

`clipboard-watch.ps1` は一定間隔でクリップボードを確認する。

初期値:

```text
500ms
```

`Get-Clipboard -Raw` を利用する。

クリップボードの内容が前回取得した値と異なる場合のみ履歴を更新する。

画像やファイルコピーは対象外とし、テキストのみ扱う。

## 7. 重複処理

同じ内容が既に履歴に存在する場合、新規登録しない。

代わりに以下を更新する。

```text
lastUsedAt = 現在時刻
useCount += 1
```

その履歴を一覧の先頭に移動する。

これによりMRU方式とする。

## 8. 並び順

一覧表示時は以下の順序とする。

```text
lastUsedAt DESC
```

つまり、最後にコピーまたは再利用した項目が一番上に表示される。

## 9. 履歴選択

`clipboard-select.ps1` を実行すると、履歴一覧を表示する。

可能な環境では `Out-GridView -PassThru` を利用する。

表示例:

```text
LastUsed             Count   Preview
2026/09/11 00:15     5       git rebase origin/main
2026/09/11 00:10     2       SELECT * FROM users...
2026/09/11 00:03     1       npm run build
```

選択した項目を `Set-Clipboard` で現在のクリップボードへ戻す。

## 10. 選択後の処理

履歴を選択した場合、

```text
lastUsedAt = 現在時刻
useCount += 1
```

として更新する。

そのため、選択した項目は次回一覧表示時に一番上へ移動する。

## 11. プレビュー

一覧には全文ではなく先頭100文字程度を表示する。

改行はスペースへ置換する。

例:

```text
SELECT id, name FROM users WHERE status = ...
```

実データとしては全文を保持する。

## 12. 除外条件

以下は保存しない。

- 空文字
- 空白だけの文字列
- 一定サイズを超える文字列
- テキスト以外のクリップボードデータ

最大文字数の初期値は以下とする。

```text
10000文字
```

## 13. セキュリティ

外部通信は一切行わない。

履歴はローカル端末内のみに保存する。

以下は将来対応候補とする。

- パスワードらしい文字列を保存しない
- URLやトークン形式を除外
- 特定文字列を含む内容を除外
- 一定日数経過後の自動削除
- 履歴保存自体を無効化するモード

## 14. エラー処理

`history.json` が存在しない場合は自動作成する。

JSONが壊れている場合はバックアップを作成し、新しい履歴ファイルを生成する。

クリップボード取得に失敗しても監視処理は終了させず、次回取得を継続する。

## 15. ロック

`clipboard-watch.ps1` の多重起動を防止する。

MutexまたはPIDファイルを利用する。

二重起動した場合はメッセージを表示して終了する。

## 16. 起動方法

利用者が毎回PowerShellを開き、`.ps1` ファイルを直接指定して実行する運用は避ける。

推奨する利用方法は、Windowsショートカット経由で `clipboard-select.ps1` を起動する方式とする。GUI を利用できる環境では PowerShell のコンソールを非表示で起動する。

ショートカットの実行対象は以下のような形式とする。

```text
powershell.exe -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File "<配置先>\clipboard-select.ps1"
```

`-NoProfile` を指定し、利用者のPowerShellプロファイルによる動作差を減らす。

`-ExecutionPolicy Bypass` は当該プロセスにのみ適用し、システム全体のExecution Policyは変更しない。

ただし、組織のセキュリティポリシーやAppLocker等によってPowerShellスクリプト実行自体が禁止されている場合は、その制限を回避しようとしない。

### ショートカット作成

`setup.ps1` を実行すると、デスクトップへ履歴ショートカットを作成し、現在ユーザーのスタートアップフォルダへ監視用ショートカットを作成して、常駐アプリも開始する。スタートメニューにはショートカットを作成しない。監視用ショートカットは `wscript.exe` から `clipboard-watch.vbs` を実行するため、コピー時を含めて PowerShell の黒いコンソールウィンドウを表示しない。

ショートカット名は以下とする。

```text
Clipboard History
```

これにより、通常利用時には `.ps1` ファイルを直接操作する必要をなくす。

## 17. キーボードショートカット

Windows標準の `Win + V` は上書きしない。

`Win + V` はWindows標準のクリップボード履歴として残し、本ツールは補助的な独自履歴として併用する。

理由は以下の通り。

- Windows標準機能を失わない
- OSアップデートによる影響を受けにくい
- PowerShellのみでWindowsキーを含むグローバルホットキーを安全に奪取する構成を避けられる
- 会社PCで低レベルキーフックや追加常駐ソフトを必要としない

本ツールの起動には、常駐監視プロセスが `RegisterHotKey` で登録するグローバルホットキーを利用する。Windowsショートカットファイルの「ショートカットキー」機能には依存しない。

ホットキーを受けた常駐プロセスは、別の PowerShell プロセスを起動せず、同一プロセス内で履歴一覧を表示する。これにより起動待ちと黒いコンソールの瞬間表示を防ぐ。

履歴一覧は閉じずに表示し続ける。監視中にクリップボードのテキストが変化したら一覧を自動更新し、利用者が行を選択したらその内容をクリップボードへ設定する。

ウィンドウの閉じるボタンは一覧を隠すだけで、常駐監視は停止しない。通知領域のアイコンから再表示し、終了操作は通知領域メニューの `Exit` に限定する。

初期推奨キーは以下とする。

```text
Ctrl + Alt + V
```

利用者は必要に応じてWindowsショートカットのプロパティから変更できる。

想定操作は以下とする。

```text
Ctrl + C
  ↓
履歴へ保存

Win + V
  ↓
Windows標準履歴

Ctrl + Alt + V
  ↓
ps-clipboard-history
  ↓
履歴一覧から選択
  ↓
Set-Clipboard
```

### Win + V の扱い

`Win + V` のフック、無効化、リマップはv1では実装しない。

将来的にも標準機能の置き換えではなく、原則として併用を推奨する。

## 18. 監視スクリプトの起動

`clipboard-watch.ps1` は履歴を記録するため継続実行が必要となる。通常は `clipboard-watch.vbs` を `wscript.exe` から実行し、コンソールを表示しない。

現在ユーザーのスタートアップフォルダにショートカットを配置してログイン時に自動起動する。Windowsタスクスケジューラへの管理者権限付き登録は必要としない。

アンインストール時は作成したショートカットのみ削除し、OS設定そのものは変更しない。

## 19. 初期バージョンの対象外

以下はv1では実装しない。

- 画像履歴
- HTML履歴
- ファイル履歴
- クラウド同期
- Windows標準Win+Vとの統合・置き換え
- 常駐GUI
- Windowsキーを含むグローバルホットキーのフック
- 暗号化
- SQLite
- 自動アップデート

## 20. v1の完成条件

以下を満たしたらv1完成とする。

```text
1. PowerShellのみで動作する
2. テキストクリップボードを監視できる
3. 直近50件を保存できる
4. 重複履歴を作らない
5. 再利用した履歴が先頭へ移動する
6. Out-GridViewから履歴を選択できる
7. 選択内容をクリップボードへ戻せる
8. PC再起動後も履歴が残る
9. 外部通信を行わない
10. 管理者権限を必要としない
11. `.ps1` を毎回直接実行せずショートカットから起動できる
12. Ctrl + Alt + V などから履歴画面を起動できる
13. Win + V のWindows標準機能を維持する
```

`ps-clipboard-history`
