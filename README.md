# ps-clipboard-history

Windows のテキストクリップボードをローカル JSON に保存し、あとから選び直せる PowerShell 専用ツールです。外部通信や管理者権限は必要ありません。

## 要件

- Windows PowerShell 5.1 以降（PowerShell 7 でも動作）
- `Get-Clipboard` / `Set-Clipboard` が利用可能な Windows

## 使い方

監視は通知領域（タスクバー右端）にアイコンを置く常駐アプリとして動作します。コンソールを表示せず、既定では 500ms ごとに確認し、`%LOCALAPPDATA%\clipboard-history\history.json` に最大 500 件を保存します。

初回・更新時ともに、リポジトリのフォルダで次の1コマンドだけ実行してください。

```powershell
.\setup.ps1
```

このコマンドは、古い本ツールのプロセスを終了してから、デスクトップの履歴ショートカット作成、ログイン時の自動起動設定、常駐アプリの起動をまとめて行います。デスクトップの **Clipboard History** も常駐アプリを開くため、旧方式の一覧画面は開きません。スタートメニューには項目を作成しません。

作成される **Clipboard History** ショートカットは履歴一覧を開きます。同時に、ログイン時に常駐アプリを起動する **Clipboard History Watcher** ショートカットを現在ユーザーのスタートアップフォルダへ作成します。どちらも `-NoProfile` とプロセス限定の `-ExecutionPolicy Bypass` を使用し、システム全体の実行ポリシーは変更しません。既存の本ツールのショートカットは更新します。

常駐アプリを起動すると、履歴ウィンドウは開いたままになります。`Ctrl + C` すると新しいコピー内容が自動で先頭に追加されます。番号列の番号を入力すると該当行を選択でき、`Enter` でコピーできます。検索欄は `Ctrl + F` で開き、クリップボード本文に対する大文字・小文字を区別しない部分一致で即時に絞り込めます。検索欄で下矢印キーを押すと一覧へ移動でき、`Esc` で検索を閉じます。

履歴一覧は読みやすさのため、12ptの文字・32pxの行高で表示します。

マウスで行をクリック、または上下矢印キーで行を選んで `Enter` を押すと、その内容をクリップボードへ戻します。コピー後も履歴ウィンドウは開いたままで、上下矢印キーだけではコピーしません。カウント列は表示しません。閉じるボタンはウィンドウを隠すだけで監視を続けます。通知領域の **Clipboard History** アイコンをダブルクリックまたは右クリック→「Open history」で再表示できます。右クリック→「Exit」で常駐を終了できます。`Win + V` は変更せず、Windows 標準のクリップボード履歴として併用します。

## オプション

両方のスクリプトは `-HistoryPath` と `-MaxHistory` を受け取ります。`-MaxHistory` の既定値は 500 です。監視スクリプトには `-IntervalMilliseconds`（既定 500）、`-MaxContentLength`（既定 10000）、テスト向けの `-RunOnce` と `-MutexName` もあります。

```powershell
.\clipboard-watch.ps1 -HistoryPath "$env:TEMP\history.json" -MaxHistory 100
```

空白のみ・10,000 文字超の内容は保存せず、重複するテキストは新規登録せずに最終利用時刻だけを更新します。JSON が壊れている場合は同じフォルダに `.corrupt-日時` 付きで退避してから、新しい履歴を作ります。

## テスト

Windows PowerShell 5.1 で、次のコマンドを実行します。

```powershell
.\tests\verify.ps1
```

履歴の重複・最大件数・旧カウントデータの削除、検索欄、行クリック/Enter操作、コピー後の自動非表示、常駐アプリ用ショートカットを検証します。GitHub Actions でも同じ検証を実行します。

履歴には機微情報をコピーしないでください。保存内容は暗号化されません。
